# 08. 매일 쓰기 위한 기능들 (#39)

"있으면 좋은 기능" 9가지 + 빠른 입력창에서 수정·삭제 + 창 옮기기.

## 데이터
- `todos`에 열 추가: `all_day`, `repeat`, `note`, `subtasks`(JSON), `spawned_id`
- 마이그레이션 도구 없이 `add_missing_columns()`: 시작할 때 모델에만 있는 열을 `ALTER TABLE … ADD COLUMN`으로 붙인다.
  기본값이 있거나 NULL을 허용하는 열만 되고, Postgres에서는 `IF NOT EXISTS`로 동시 시작에도 안전
- 하루 종일: `due_at`은 그날 23:59로 저장하고 화면에는 날짜만. 0시로 두면 하루가 시작하자마자 "지남"이 된다
- 반복: 완료하는 순간 다음 회차를 새 할 일로 만든다(`spawned_id`에 기록). 완료를 되돌리면 그 회차도 지운다.
  오래 밀린 일을 완료하면 다음 마감은 지난 날짜가 아니라 오늘 이후. 매월 31일은 없는 달엔 말일

## 화면
- 되돌리기: 삭제는 화면에서만 숨기고 5초 뒤에 서버로 보낸다. 창을 닫으면(`pagehide`) 바로 보낸다(`keepalive`)
- 검색은 제목·메모·하위 항목, 완료한 일도 같이
- 키보드 조작은 한글 입력 상태에서도 되게 `e.code`(KeyJ 등)로 판단
- 미루기 메뉴가 `overflow-hidden`에 잘려서, 선택 배경의 모서리는 줄 자체를 둥글게 처리

## 비서
- 제목이 분명한 삭제·완료("치과 예약 삭제")는 LLM 없이 처리: 빠른 입력창에서 몇 초씩 기다리지 않고, 작은 모델이 엉뚱한 항목을 고르지도 않는다.
  후보가 여럿이면 되묻고, 못 찾거나 추가·수정이 섞여 있으면 LLM에게 넘긴다
- 같은 제목·같은 마감의 할 일은 다시 추가하지 않는다
- "ㄴㅇㄹ" 같은 입력에 모델이 아무 할 일이나 고치던 문제: 글자·숫자가 없으면 LLM을 부르지 않는다
- 답변에서 `(날짜 참고: …)`와 ISO 날짜를 지운다. 날짜만 오거나 0시 정각이면 하루 종일로 저장

## 맥 앱
- 창 옮기기: 웹 화면이 창 전체를 덮어 제목 막대를 잡을 수 없었다 → 맨 위 24px에 투명한 `DragStrip`을 얹어 `performDrag`
- 빠른 입력창: 제목을 치면 남은 할 일 중 맞는 것 5개까지 아래에 표시. `↓`로 고르고 `Enter` 완료 / `⌘⌫` 삭제 / `Tab` 제목 수정
- 마감 알림: 1분마다 목록을 받을 때 확인. 마감 10분 전 한 번, 오전(8~12시) 중 처음 확인할 때 오늘 요약 한 번.
  알린 기록은 `UserDefaults`에 남겨 앱을 다시 켜도 중복되지 않는다

## 확인
- pytest 49개 통과 (반복·되돌리기·하루 종일·마이그레이션·빠른 명령·중복 방지)
- 브라우저: 키보드 이동/완료/되돌리기/수정/삭제, 미루기, 검색, 하루 종일 선택
- 맥 앱: 빌드와 입력창 열기까지만 확인. 입력창의 결과 줄 모양·키 조작, 알림 배너, 창 끌기는 눈으로 확인하지 못함
