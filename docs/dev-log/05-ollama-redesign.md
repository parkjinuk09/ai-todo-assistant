# 05. 로컬 LLM(Ollama) 전환 + 화면 재설계

- 기간: 2026-11-15
- 이슈: #19

## 배경
- Vercel AI Gateway는 무료 크레딧을 쓰려면 결제 카드 등록이 필요했다(배포 후 403으로 확인). 다른 무료 API도 대부분 18세 이상 약관이라 쓸 수 없었다.
- 이 서비스는 **나 혼자 내 맥에서 쓰는 도구**다. 그렇다면 모델도 내 맥에서 돌리면 된다 → Ollama.
- 동시에 화면이 "AI가 만든 티가 나는 디자인"(보라 그라데이션 카드, 이모지 제목, 추상적인 문구)이었고, 실제로 동작하지 않거나 쓰이지 않는 부분이 섞여 있었다.

## 1. 제공자 교체: 환경변수 세 개
OpenAI 호환 API로 짜 둔 덕분에 코드는 거의 그대로다.
```
LLM_BASE_URL=http://localhost:11434/v1   # Ollama
LLM_API_KEY=ollama                       # Ollama는 키를 검사하지 않음
LLM_MODEL=qwen2.5:7b
```
- AI Gateway 전용 코드(OIDC 토큰 미들웨어, ContextVar)는 삭제.
- 연결 실패(`APIConnectionError`)·모델 미설치(`NotFoundError`)를 `AIUnavailable`로 바꿔 **503 + 고칠 방법**(`ollama serve`, `ollama pull …`)을 응답.
- `/health`가 `llm`, `llm_problem`, `model`을 내려 준다. 프론트는 이걸 보고 채팅 입력을 막고 이유를 그대로 보여 준다. 배포본(Vercel)에서는 자연히 "로컬 모델 서버에 연결할 수 없어"가 표시된다.

## 2. 작은 모델에 맞춘 에이전트 조정
처음 `llama3.1`(8B)로 붙였을 때 실제로 본 실패와 대응:

| 실패 | 원인 | 대응 |
|---|---|---|
| 날짜를 2023년으로 계산 | 현재 시각을 줘도 날짜 계산을 틀림 | 서버가 **2주치 달력**(`2026-11-17 다음주 화요일 = 모레`)을 만들어 프롬프트에 넣음. 모델은 찾아서 쓰기만 함 |
| "다음주 화요일"을 일요일로 | 주 경계(월요일 시작) 계산 실패 | 달력 각 줄에 `이번주/다음주/다다음주` 표기 |
| 도구 호출 대신 JSON을 글로 출력 | 형식 오류 후 포기 | `_parse_dt`가 `2026-11-16`, `2026-11-16 15:00`, `Z` 접미사까지 허용 |
| "헬스 완료" → "list_todos를 먼저 호출해 주세요" | 조회→수정 2단계를 못 이어감 | **남은 할 일 스냅샷(id 포함)을 프롬프트에 넣어** 조회 단계 제거 |
| 같은 실패 답을 반복 | 대화 기록 속 실패 답을 따라 함 | 대화 기록 20 → 4개 |
| 답변에 달력·목록을 그대로 붙임 | 프롬프트 에코 | `_clean_reply`로 마커 이후와 `id=` 줄 제거 |
| 한국어 제목이 깨짐 ("호닱 번호남…") | 모델 자체의 한국어 한계 | 모델을 `qwen2.5:7b`로 교체 |

모델 비교 (같은 프롬프트, M-series 16GB):

| 모델 | 추가(날짜) | 완료 | 수정 | 한국어 | 응답 시간 |
|---|---|---|---|---|---|
| llama3.1 8B | ✅ | ✅ | ✅ | ❌ 제목 깨짐 | — |
| qwen2.5 7B | — | — | — | — | — |

## 3. 버그: LLM 대체 문장이 캐시·확정 저장됨
브라우저 테스트 중 발견. 모델이 꺼져 있을 때 브리핑·월간 회고는 규칙 기반 문장으로 대체되는데,
- 브리핑: 대체 문장이 **10분간 캐시** → 모델을 켜도 옛 문장이 계속 보임
- 지난 달 리포트: 대체 문장이 **확정본으로 DB에 영구 저장**

→ 대체 문장으로 만든 응답은 캐시에서 바로 지우고, 확정 저장도 하지 않는다. 테스트 2개 추가
(`test_llm_fallback_text_is_not_cached`, `test_past_month_not_finalized_without_llm`).

## 4. 화면 재설계
기준: **이 화면은 나만 쓰는 도구다.** 장식 대신 정보, 추상적인 문구 대신 지금 상태.

| 전 | 후 |
|---|---|
| 보라 그라데이션 브리핑 카드, 이모지 제목 | 종이색 배경 + 먹색 글자 + 강조색 1개(밀린 일·중요). 선과 여백으로만 구분 |
| 할 일/완료/전체 필터 탭 | 마감 기준 자동 분류: **밀린 일 → 오늘 → 다가오는 일 → 날짜 없음**, 완료는 접기 |
| 우선순위 색 점 3종 | "중요"만 글자로 표시 (보통/나중에는 표시할 이유가 없음) |
| 말풍선 채팅 | "나 / 비서" 라벨의 기록형 로그, 바뀐 내용은 `→ 추가: 치과` 줄로 |
| "✨ 비서에게 말로 추가해 보세요" | "남은 할 일이 없어. 위에 직접 적거나 …" (실제 방법) |
| 응답 대기 "처리 중…" | 경과 초 + "로컬 모델이라 10~20초" (실제 대기 시간) |
| 모델 상태 표시 없음 | 서버가 준 이유 그대로 + "다시 확인" |

한글 가독성: `word-break: keep-all`, 숫자는 `tabular-nums`, 제목은 자르지 않고 줄바꿈.

## 5. 정리한 것 (쓰이지 않던 것)
- `GET /reports/months`: 프론트가 한 번도 호출하지 않음 → 라우트·서비스 함수·테스트 삭제
- AI Gateway OIDC 미들웨어, `VERCEL_OIDC_TOKEN` 처리 → 삭제
- 할 일 추가·체크·삭제 실패 시 **에러가 화면에 안 뜨고 콘솔에만 남던 문제** → 낙관적 업데이트 실패 시 서버 상태로 되돌리고 에러 표시, 추가 실패 시 입력값 유지
- 기본 CSS가 Tailwind 유틸리티를 덮어써 버튼 글자가 안 보이던 문제 → `@layer base`로 이동
