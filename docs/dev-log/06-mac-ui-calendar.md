# 06. 맥 스타일 화면 + 캘린더

## 목표
- macOS 기본 앱처럼 회색 반투명 재질과 정돈된 레이아웃
- 할 일을 날짜로 보는 캘린더. 칸마다 테두리를 두르는 흔한 달력 대신 여백과 점으로 정리

## 구조
| 영역 | 내용 |
|---|---|
| 사이드바 | 반투명(`backdrop-blur`), 할 일 / 캘린더 / 월간 기록 / 비서(1280px 미만일 때만), 밀린 일 개수 |
| 본문 | 시스템 설정 앱처럼 둥근 묶음 목록, 미리알림 앱 같은 동그란 체크 |
| 비서 | 1280px 이상에서 오른쪽 고정. 말풍선, 처리한 일은 `✓` 한 줄 |

색은 `@theme` 토큰(`--color-sidebar`, `--color-surface`, `--color-group`, `--color-field` 등)으로만 쓰고, 다크 모드는 `prefers-color-scheme`에서 같은 토큰만 다시 정의한다. 컴포넌트 쪽은 바꿀 게 없다.

## 캘린더
- 6주 x 7일 칸. 오늘 날짜는 빨간 원, 이번 달이 아닌 날은 흐리게
- 칸에는 최대 3개 제목 + `+N개`, 분류 색 점
- 날짜를 누르면 아래에 그날 목록과 추가 입력(마감 기본값: 그날 오전 9시)
- 할 일을 다른 칸으로 끌어다 놓으면 `PATCH /todos/{id}`로 날짜만 바꾼다(시·분 유지, `moveToDay`)

## 브라우저 확인 중 고친 것
| 문제 | 원인 | 수정 |
|---|---|---|
| 1024px에서 캘린더 칸이 55px, 제목이 두 글자만 보임 | 비서 칸(320px)이 1024px부터 고정 | 비서 고정 칸을 1280px 이상으로 |
| 휴대폰 폭에서 제목이 한 글자로 잘려 쓸모없음 | 칸 폭이 약 45px | 640px 미만에서는 제목 대신 색 점만, 칸 높이 52px |
| 터치 기기에 "끌어다 놓기" 안내가 뜸 | 터치에서는 HTML 드래그가 안 됨 | `hover:hover`일 때만 안내 표시 |

## 확인
- 1024 / 1440 / 375px, 라이트·다크에서 목록·캘린더·월간 기록·비서 직접 사용
- 끌어 옮기기: 17일 15:00 → 19일 15:00 저장 확인
- 날짜 선택 후 추가: 19일 09:00로 저장 확인
- 비서: "금요일 저녁 7시 영화 보기 추가해줘" → 11/20 19:00 추가
- eslint, vite build, pytest 36개 통과
